# Conquer Crypto — frontend demostrativo

## Requisitos
Node.js compatible con Webpack 5 y npm.

## Desarrollo
```bash
npm install
npm start
```
Abrir http://localhost:8080/ (Webpack Dev Server).

## Producción
```bash
npm run build
```
Genera `css/style.css` y `js/bundle.js` en la raíz del proyecto, junto a los HTML.
El proyecto está organizado como sitio multipágina de rutas relativas y es apto para servir desde una subruta, como GitHub Pages.

**Alcance:** demostración frontend; registro y login no autentican usuarios reales.
